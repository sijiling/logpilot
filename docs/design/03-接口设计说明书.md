# LogPilot 接口设计说明书

## 1. 通用约定

- Base URL：`http://localhost:8080`
- Content-Type：JSON 接口使用 `application/json`；上传使用 `multipart/form-data`。
- 请求 ID：客户端可传 `X-Request-ID`，否则服务端生成并通过同名响应头返回。
- 时间：RFC 3339 UTC。
- ID：UUID v7 字符串。

错误响应：

```json
{
  "error": {
    "code": "INVALID_ARGUMENT",
    "message": "question is required",
    "request_id": "0195f11a-cc44-7e41-a5f2-5c57bdcb6834"
  }
}
```

| HTTP | 业务码 | 场景 |
| --- | --- | --- |
| 400 | `INVALID_ARGUMENT` | 参数格式或范围错误 |
| 404 | `SESSION_NOT_FOUND` | 会话不存在 |
| 409 | `DOCUMENT_CONFLICT` | 文档正在处理 |
| 413 | `PAYLOAD_TOO_LARGE` | 文档或日志超过限制 |
| 429 | `TOO_MANY_REQUESTS` | 诊断并发已满 |
| 502 | `UPSTREAM_ERROR` | 模型、Embedding 或 Qdrant 调用失败 |
| 504 | `DIAGNOSIS_TIMEOUT` | 诊断超过 60 秒 |
| 500 | `INTERNAL_ERROR` | 未预期错误 |

## 2. 上传知识文档

`POST /api/v1/documents`

表单字段：`file` 必填，`.md`；`title` 可选。

```bash
curl -F "file=@testdata/runbooks/go-panic.md" \
  -F "title=Go Panic 处理手册" \
  http://localhost:8080/api/v1/documents
```

成功：HTTP 201；重复内容：HTTP 200 且 `duplicated=true`。

```json
{
  "document_id": "0195f11a-cc44-7e41-a5f2-5c57bdcb6834",
  "title": "Go Panic 处理手册",
  "status": "ready",
  "chunk_count": 5,
  "duplicated": false
}
```

## 3. 普通诊断

`POST /api/v1/diagnoses`

```json
{
  "session_id": "",
  "question": "接口持续返回 500，可能是什么原因？",
  "logs": "2026-09-29T10:00:00Z ERROR panic: runtime error: invalid memory address",
  "service": "video-api"
}
```

`session_id` 为空时创建新会话。成功响应：

```json
{
  "session_id": "0195f11a-cc44-7e41-a5f2-5c57bdcb6834",
  "diagnosis_id": "0195f11c-21a9-77ab-a238-ad2042b22e74",
  "summary": "服务出现 Go 空指针 panic，健康检查当前不可用。",
  "causes": ["请求路径中的对象未完成空值校验"],
  "steps": ["根据堆栈首行定位函数", "检查该函数的指针返回值", "补充 nil 分支测试"],
  "warnings": ["结论基于现有日志，未执行自动修复"],
  "evidence": [
    {"type": "document", "title": "Go Panic 处理手册", "chunk_index": 2, "score": 0.86}
  ],
  "tool_calls": [
    {"name": "analyze_log", "status": "succeeded", "duration_ms": 2},
    {"name": "search_knowledge", "status": "succeeded", "duration_ms": 41}
  ],
  "rounds": 3,
  "created_at": "2026-09-29T10:00:04Z"
}
```

## 4. 流式诊断

`POST /api/v1/diagnoses/stream`

请求体与普通诊断相同，响应 `Content-Type: text/event-stream`。

```text
event: session
data: {"session_id":"0195f11a-cc44-7e41-a5f2-5c57bdcb6834"}

event: tool_call
data: {"round":1,"name":"analyze_log"}

event: tool_result
data: {"round":1,"name":"analyze_log","status":"succeeded","duration_ms":2}

event: answer
data: {"delta":"日志显示服务发生 Go 空指针 panic。"}

event: done
data: {"diagnosis_id":"0195f11c-21a9-77ab-a238-ad2042b22e74","rounds":3}
```

`thinking` 事件只表示阶段，例如“正在检索知识库”，不得输出模型隐藏思维链。

## 5. 查询会话

`GET /api/v1/sessions/{session_id}`

```json
{
  "id": "0195f11a-cc44-7e41-a5f2-5c57bdcb6834",
  "created_at": "2026-09-29T10:00:00Z",
  "updated_at": "2026-09-29T10:00:04Z",
  "messages": [
    {"role": "user", "content": "接口持续返回 500，可能是什么原因？"},
    {"role": "assistant", "content": "服务出现 Go 空指针 panic……"}
  ]
}
```

## 6. 状态接口

- `GET /healthz` → `200 {"status":"ok"}`
- `GET /readyz` → 全部就绪返回 200，否则 503 并列出失败组件。
- `GET /metrics` → Prometheus 文本格式。
