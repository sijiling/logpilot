**LogPilot 智能日志诊断 Agent｜Go / Gin / RAG / Qdrant / Ollama / SSE / Docker**

- 基于 CloudWeGo Eino 构建日志诊断 Agent，通过 ReAct 模式编排知识检索、日志分析和服务健康检查工具，结合 MaxStep、Context 和 60 秒超时避免无限循环和资源失控。

## 2. 30 秒项目介绍

LogPilot 是一个用 Go 实现的智能日志诊断 Agent。和普通聊天机器人不同，它会在受控的 ReAct 循环中自主选择知识检索、日志解析和健康检查工具，再根据真实工具结果生成带引用的诊断建议。我重点解决了三个问题：如何限制 Agent 行为、如何让结论可追踪，以及如何安全地调用外部工具。

## 3. 面试高频问题

### 为什么选择 Eino？

Eino 是 Go 生态中的 Agent 开发框架，已经提供 ChatModel、Tool、ReAct、流式输出、Callback 和中断能力。项目重点是运维诊断业务、安全边界和可观测性，因此复用框架能力，避免重复实现通用编排逻辑；同时通过 Fake ChatModel 和 Callback 验证 Agent 的行为边界。

### RAG 为什么使用 Qdrant？

Qdrant 支持余弦相似度、Payload 和过滤，HTTP API 清晰；对个人项目而言比自建向量索引可靠，又能展示独立向量存储的工程接入。业务元数据仍放 SQLite，向量索引可以重建。

### 如何避免 Agent 无限循环？

使用最大 6 轮、60 秒总超时、Context 取消和工具白名单四层限制。达到轮次上限后不再接受工具调用，而是要求模型根据已有证据输出总结。

### 如何测试模型相关逻辑？

Agent 单元测试使用脚本化 Fake ChatModel，按预设顺序返回工具调用和最终答案，因此可以确定性验证 MaxStep、错误和取消传播。真实模型只用于独立评测，不进入普通 CI 门禁。

### 如何防止工具调用产生安全问题？

模型只能选择预注册工具，参数先经过 JSON Schema 与业务校验。健康检查不接受任意 URL，只接受配置中的服务名，并禁用重定向、设置超时和响应体上限；系统完全不提供 Shell 工具。

## 4. 演示顺序

1. 展示一份 Go Panic 运维手册并上传。
2. 提交一段含空指针堆栈的日志。
3. 在 SSE 输出中展示日志分析和知识检索工具事件。
4. 展示带引用的最终诊断结果。
5. 查询历史会话，展示工具轨迹。
6. 打开 Prometheus 指标说明 Agent 轮次和工具耗时。
