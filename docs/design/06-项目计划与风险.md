# LogPilot 项目计划与风险

## 1. 迭代计划

| 工作日 | 里程碑 | 可验收交付物 |
| --- | --- | --- |
| 1 | 项目骨架 | 配置、HTTP Server、健康检查、优雅停机、质量工具 |
| 2 | 数据层 | SQLite Migration、会话与文档 Repository |
| 3 | 文档处理 | 上传校验、分块、重复检测、Fake Embedder 测试 |
| 4 | RAG | 特征哈希向量、Qdrant Upsert/Search、集成测试 |
| 5 | 工具体系 | Eino Tool、日志分析、知识检索、健康检查 |
| 6 | Agent 核心 | Eino ReAct Agent、MaxStep/超时控制、Fake ChatModel 测试 |
| 7 | 诊断 API | 普通诊断、结构化结果、持久化 |
| 8 | 流式输出 | SSE 事件、客户端取消传播、并发限制 |
| 9 | 工程完善 | 指标、日志、Docker Compose、错误处理 |
| 10 | 验收交付 | 评测集、README、演示脚本、架构图和简历描述 |

## 2. 版本范围

### v0.1.0 MVP

完成本文档定义的 Markdown RAG、三种工具、普通/SSE 诊断、会话查询和容器化交付。

### v0.2.0 可选增强

仅在 v0.1.0 通过验收后考虑：文档删除/重建索引、会话分页、诊断反馈、Web 演示页。多 Agent、自动执行 Shell 和 Kubernetes 接入不在近期范围。

## 3. 风险登记

| 风险 | 概率 | 影响 | 应对措施 |
| --- | --- | --- | --- |
| 本地模型性能不足 | 中 | 高 | 模型层使用 OpenAI 兼容接口，可切换云模型；评测记录具体模型 |
| Agent 无限工具循环 | 中 | 高 | 最大 6 轮、60 秒总超时、工具名白名单 |
| 检索结果不相关 | 中 | 中 | 固定分块策略、0.55 阈值、Hit@3 评测集 |
| 健康检查造成 SSRF | 低 | 高 | 只接受服务名，地址来自管理员配置，禁止重定向 |
| 日志泄露敏感信息 | 中 | 高 | 模型调用和持久化前统一脱敏，测试覆盖密钥格式 |
| 项目范围膨胀 | 高 | 中 | 以 v0.1.0 验收清单为冻结范围，不做前端和自动修复 |
| Qdrant 与 SQLite 不一致 | 中 | 中 | 状态机、补偿删除和可重建索引 |

## 4. 配置清单

| 环境变量 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `LOGPILOT_HTTP_ADDR` | 否 | `:8080` | 监听地址 |
| `LOGPILOT_DATABASE_PATH` | 否 | `./data/logpilot.db` | SQLite 文件 |
| `LOGPILOT_LLM_BASE_URL` | 是 | 无 | OpenAI 兼容地址 |
| `LOGPILOT_LLM_API_KEY` | 否 | 空 | 本地 Ollama 可为空 |
| `LOGPILOT_LLM_MODEL` | 是 | 无 | 对话模型名 |
| `LOGPILOT_EMBED_DIMENSION` | 是 | 无 | 向量维度 |
| `LOGPILOT_QDRANT_URL` | 否 | `http://qdrant:6333` | Qdrant 地址 |
| `LOGPILOT_SERVICE_TARGETS` | 否 | 空 | `name=url` 逗号分隔白名单 |

## 5. Definition of Done

- 需求对应测试用例并通过。
- 新增导出标识符拥有有效 Go 文档注释。
- 外部调用具有 Context、超时和受限响应体。
- README 的命令可从干净环境执行。
- 示例输出来自真实运行，不伪造性能数据。
- 简历只写已经实现并可演示的能力。
