# LogPilot 数据设计说明书

## 1. SQLite 表

### documents

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | TEXT | PK | UUID v7 |
| title | TEXT | NOT NULL | 文档标题 |
| content_hash | TEXT | UNIQUE, NOT NULL | 原始内容 SHA-256 |
| status | TEXT | NOT NULL | processing/ready/failed |
| chunk_count | INTEGER | NOT NULL DEFAULT 0 | 分块数 |
| error_message | TEXT | NOT NULL DEFAULT '' | 失败原因，不包含密钥 |
| created_at | TEXT | NOT NULL | RFC 3339 UTC |
| updated_at | TEXT | NOT NULL | RFC 3339 UTC |

### sessions

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | TEXT | PK | UUID v7 |
| title | TEXT | NOT NULL DEFAULT '' | 首次问题截断生成 |
| created_at | TEXT | NOT NULL | 创建时间 |
| updated_at | TEXT | NOT NULL | 最近消息时间 |

### messages

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | TEXT | PK | UUID v7 |
| session_id | TEXT | FK, NOT NULL | 所属会话 |
| role | TEXT | NOT NULL | user/assistant/tool |
| content | TEXT | NOT NULL | 已脱敏内容 |
| created_at | TEXT | NOT NULL | 创建时间 |

索引：`messages(session_id, created_at)`。

### diagnoses

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | TEXT | PK | UUID v7 |
| session_id | TEXT | FK, NOT NULL | 所属会话 |
| summary_json | TEXT | NOT NULL | 结构化诊断结果 |
| rounds | INTEGER | NOT NULL | Agent 轮数 |
| status | TEXT | NOT NULL | succeeded/failed/cancelled |
| created_at | TEXT | NOT NULL | 完成时间 |

### tool_runs

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | TEXT | PK | UUID v7 |
| diagnosis_id | TEXT | FK, NOT NULL | 所属诊断 |
| round | INTEGER | NOT NULL | 调用轮次 |
| tool_name | TEXT | NOT NULL | 工具名 |
| argument_summary | TEXT | NOT NULL | 脱敏后的参数摘要 |
| result_summary | TEXT | NOT NULL | 截断后的结果摘要 |
| status | TEXT | NOT NULL | succeeded/failed |
| duration_ms | INTEGER | NOT NULL | 执行耗时 |
| created_at | TEXT | NOT NULL | 调用时间 |

索引：`tool_runs(diagnosis_id, round)`。

## 2. Qdrant Collection

Collection 名称：`logpilot_documents`；距离算法：Cosine；向量维度从 Embedding 配置读取，启动时与现有 Collection 校验一致性。

Payload：

```json
{
  "document_id": "0195f11a-cc44-7e41-a5f2-5c57bdcb6834",
  "title": "Go Panic 处理手册",
  "chunk_index": 2,
  "content": "当服务出现 nil pointer panic 时……",
  "content_hash": "sha256:..."
}
```

Point ID 使用由 `document_id + chunk_index` 派生的确定性 UUID，确保重试 Upsert 不产生重复数据。

## 3. 一致性策略

- SQLite 是文档元数据和业务记录的事实来源，Qdrant 仅保存可重建的检索索引。
- 文档先创建 `processing` 记录，再写向量；全部向量成功后更新为 `ready`。
- 写向量失败时删除该文档的向量并更新为 `failed`。
- 会话消息和诊断结果在单个 SQLite 事务中提交。

## 4. 数据保留

- MVP 不自动删除数据。
- 日志正文保存前脱敏并限制为 64 KiB。
- 工具结果摘要最大 4 KiB，完整健康检查响应不落库。
- API Key、Authorization 请求头和模型原始隐藏推理不得落库。
